# Agent Graph

Build agentic systems as a graph. Nodes are the orchestrator (King), tools (Ammunition),
sub-agents (Knights), checks (Advisors), and guardrails (Wardens). Typed edges say who
talks to whom. The UI builds, edits, runs, and observes the graph.

- `DESIGN.md` — node and edge model, graph JSON, runtime, UI flow, critique.
- `index.html` — runnable mock of all six steps. Open it in a browser. No build, no API calls yet.
